# Portfolio

Sitio personal. Astro + Tailwind, salida estática.

```sh
pnpm install
pnpm dev      # localhost:4321
pnpm build
```

Los sonidos de interfaz y el dither de los iconos se generan en el
navegador, no hay archivos de audio ni de imagen para ellos.
`playground/` contiene el banco de pruebas de las paletas de sonido y
queda fuera del build.
